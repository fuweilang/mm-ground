# ui-shell-consistency

两端（中台 / 猛犸智能体）的外壳层级要一致：底部不再堆「像菜单项」的东西，用户菜单内容与视觉统一，跨产品切换有固定位置。

## 问题

- **中台** `layouts/AppShell.vue` 侧栏底部是「猛犸智能体 + 折叠按钮」。猛犸智能体完全继承了 nav 项的形态（同款图标尺寸、满宽、同款 hover），读起来就是第五个菜单项；它实际是跨产品跳转。
- **Agent** `Sidebar.tsx` 的 `styles.sidebarUser` 纵向堆三行：企业控制台、下载客户端、用户头像。三行图标/字号/行高/hover 全同构，底部成了「第二个菜单」，最该被看见的用户名反而最弱。
- 用户信息一处右上（中台）、一处左下（Agent），跨产品来回切换时「我在哪、去哪切」没有统一答案。位置本身各合惯例，问题在**内容与视觉没有统一**，且跨产品跳转分散在两个角落。

## 目标

- 底部只承担两类东西：**导航组的最后一项** + **账号区**。账号区是一个整块用户卡，不再是列表行。
- 中台侧栏底部的猛犸智能体改成 **ghost 胶囊 + `↗` + 次级色**（`#667085` 文字 / `#dfe5ef` 描边，hover 升主色），与折叠按钮同排左右分置，上方细分隔。不用主色——主色代表「当前所在/本页主操作」。
- Agent 底部：「企业控制台」作为导航组最后一项并隔开；用户卡（头像 + 名字 + chevron）贴底、整块可点。
- **用户菜单内容与视觉统一**：头像、名字、菜单项与顺序一致（企业设置 → 下载/版本 → 退出登录），退出登录永远在菜单内，不单独放按钮。
- **跨产品切换器**：两端都在**左上角品牌旁**提供同一个切换器（`猛犸中台 ⇄ 猛犸智能体`）并标明当前所在；中台底部的猛犸智能体、Agent 底部的企业控制台，语义上都归到这里。

## 范围

- `ground/apps/frontend/src/layouts/AppShell.vue`（sidebar-footer、brand 区）。
- `Octop/dashboard/src/layouts/Sidebar.tsx`、`Sidebar.module.less`、`components/AvatarDropdown.tsx`、`locales/{zh,en}.json`。
- 用户菜单项顺序、文案 key 的两端对齐。

## 非目标

- **不强行统一位置**：中台用户菜单留在右上、Agent 留在左下，各自符合管理后台 / 聊天应用惯例。
- 不改 PeecAI 后台。
- 不合并两个前端工程、不动登录与会话逻辑。
- 不改下载弹窗本体（见 `desktop-download-modal`）。
- 不做 `/download` 独立页面。
